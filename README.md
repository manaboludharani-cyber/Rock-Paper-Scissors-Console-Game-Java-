# Rock-Paper-Scissors Console Game

## Description
Rock-Paper-Scissors Console Game is a simple Java-based application where a user plays the classic Rock-Paper-Scissors game against the computer. The computer randomly selects Rock, Paper, or Scissors, and the program compares both choices to determine the winner.

This project demonstrates basic Java concepts such as user input, random number generation, arrays, conditional statements, and program logic.

## Features
- User vs Computer gameplay
- Random computer choice selection
- Win, lose, and draw detection
- Simple console interface
- Input validation for user choices

## Game Rules
- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choices result in a Draw

## Technologies Used
- Java
- Scanner Class
- Random Class
- Arrays
- Conditional Statements
